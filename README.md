# jrxy_auto_cf

运行于 **Cloudflare Workers + D1 + Queues** 的轻量 jrxy 签到与查寝管理项目。支持手机和桌面，无需自建服务器、Docker、付费容器或 OCR；GitHub 保存代码，Cloudflare 自动构建运行。

## 功能

- **签到 / 查寝**：保留原登录、任务选择、附加表单、动态密钥与加密提交流程，支持登录测试、只探测及范围获取。
- **每日计划**：北京时间、账号权重、暂停/恢复，默认串行，可选2或3并发。
- **可靠性**：确认成功即结束；暂时失败整轮重试，提交未知先复查，队列与报告中断可恢复。
- **自助授权**：首页 `/` 输入一次性授权码开通；每批最多10码，默认24小时，可复制未使用新码及整批撤销，到期清理个人数据。
- **管理与通知**：`/admin` 独立账号密码，账号配置加密、脱敏日志、Server酱及后台Webhook通知。

不支持照片、收集、政工及教师日志任务；遇验证码停止并提示人工处理。

## 快速部署

1. Fork本仓库，在Cloudflare创建D1数据库 `jrxy-auto-cf` 和Queue `jrxy-auto-cf-jobs`。
2. 创建Worker并连接GitHub，生产分支选 `main`，按下表配置。构建环境设置 **`D1_DATABASE_ID`**；使用[完整部署命令](cloudflare/README.md#构建环境注入数据库id)，不要把真实ID或令牌提交到仓库。

   | 配置 | 值 |
   |---|---|
   | Worker名称 | `jrxy-auto-cf` |
   | 根目录 | `cloudflare` |
   | Node.js | 22或更新 |
   | 构建命令 | `npm run check && npm test && npm run build` |
   | 部署流程 | 注入数据库ID → `npm run deploy`（自动增量迁移后发布） |

3. 部署后，在Worker的“变量和机密”设置三个**运行时Secret**：

   | Secret | 内容 |
   |---|---|
   | `ADMIN_USERNAME` | 独立管理员用户名 |
   | `ADMIN_PASSWORD` | 至少12字符的强密码 |
   | `ENCRYPTION_KEY` | 32随机字节的标准Base64 |

   仅首次安装生成加密密钥：
   ```bash
   node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
   ```
4. 访问 `/admin`，核对账号、实际位置与计划时间，先做登录测试和探测，再在官方应用核实签到结果。默认用户页为 `/`。

**升级必须沿用原D1、队列和ENCRYPTION_KEY，不要重新生成密钥。** 部署会应用增量迁移；非生产分支只检查/干跑，不复用生产资源。详细步骤见[部署与升级手册](cloudflare/README.md)。

## 执行规则

- 默认 **北京时间22:05**；首次授权可开启尚未由管理员设置的初始计划，管理员已保存的开关不会被覆盖。
- **本次任务第一次确认成功，后续不再重试或重复提交**；其他账号继续执行，次日新任务照常参加计划。
- 定时暂时异常：所有账号完成当前轮后等待5分钟，最多额外重试5次，共最多6轮。原Python默认额外2次，本版按新要求调整；旧在途批次保留原预算。
- 提交结果未知：保留同任务检查点，后续只复查；确认未签才允许重提。失败、无任务、待确认都不是成功。
- 默认并发1，可选2/3；明确网络暂时错误后，下一重试轮降为串行，不改变全局设置。验证码和418/429不盲重试。
- 普通学校请求默认等待60秒，单账号总时限300秒；密钥协商和签到提交仍为20秒。后台显示实际参数；加时不保证解决学校网关或出口问题。
- 手动/普通批量保持单次；单账号和“签到全部”都会接续已有签到/重试进度，空闲账号才新建。同一未结束批次的成功账号不重签；暂停、到期和其他操作占用会分别提示。通知失败不改写签到结果，补日志或恢复报告不重签。
- deviceId沿用已有值或首次生成并固定，不是读取手机真实ID。暂停/到期禁止新提交；已发出的请求无法撤回。
- 排障时在执行结果或历史日志展开“逐请求诊断”，点击“复制脱敏诊断”反馈；仅含版本、阶段、域名、耗时和状态，不含账号或凭据。

学校网络、任务窗口、设备限制及免费配额不由项目控制，不能保证每次成功。未知旧任务跨日后可能需人工核实；不要同时在旧服务器与Worker执行同一账号任务。
