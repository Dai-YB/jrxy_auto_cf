# jrxy_auto_cf 功能对应与兼容边界

发布前逐阶段审查与修复记录见 [流程审查报告](../docs/FLOW_REVIEW.md)。

## 当前要求

**免费Cloudflare、无OCR；签到/查寝、暂停/恢复、管理员账号密码登录、手机适配、通知、日志与每日定时。** 沿用用户现有 GitHub → Cloudflare 自动构建，不增加第二个运行平台。

最新要求允许重做界面，因此不再要求CSS/布局逐字等于旧页面。学校协议、账号设备、表单规则、结果与通知逻辑继续复用同一实现，不因界面或部署入口改变。

| 签到/查寝 | AutoSign / getApis | 保留1/2接口；照片及0/3/4移除 |
| 页面 | 用户要求美化与手机适配 | 浅色桌面列表+手机卡片、独立登录、原功能入口；不使用前端框架/第三方字体 |

## 明确不同或不保证的部分

1. **管理登录与暂停是明确新增行为**。旧WEB_TOKEN和导入脚本鉴权必须升级；管理员Secret不等于校园账号。
2. **页面不再沿用旧布局**，但业务入口保留；`sync-ui.py` 已退役，防止回滚覆盖新页面。
3. **执行API为异步202+任务查询**，直接调用旧同步API的外部脚本需适配。前端已处理。
4. **日志安全**：不照搬原代码输出sessionToken/密钥的调试文本；管理员密码、Cookie和通知凭据不写日志。
5. **暂停并发边界**：提交检查点写入后视为提交阶段，暂停接口会提示可能已提交；无法撤回已发出的网络请求。
6. **通知不具备服务端幂等键**：发送期间崩溃可产生未知状态，保守不重发，不承诺严格恰好一次。
7. **学校与平台限制**：公网HTTPS、有效证书、Cloudflare出口可达；本地requests代理、校园内网、verify=False、验证码/MFA不等价支持。不静默绕过。
8. **免费额度非无限**：本地测试不模拟远程CPU配额；大登录页/多重重定向/账号规模可能超出免费额度，需要看Metrics。
9. **原CLI实验分支**：Android/App、未被当前Web使用的APPRISE插件保留在Python目录，不是当前Cloudflare Web入口。
10. **真实实测边界**：发布源码不等于部署远程或真实验证。未使用真实学校账号登录/签到或发送实际通知，本地通过不代表实际学校已验证。

## 回归要求

- 保留原Python纯规则对照、坐标签名和协议测试，不改预期以掩盖协议变化。
- 鉴权覆盖：安全Cookie、错误密码/用户名、限速、CSRF/Origin、退出/过期/轮换、旧令牌拒绝。
- 暂停覆盖：新任务、排队/重试、提交前暂停再恢复、暂停后不补跑、提交中提示、已完成结果仍通知。
- 迁移覆盖：从0001~0003旧数据库升级后，账号密文/deviceId/计划/日志保持。
- 通知覆盖：原格式、响应分类、真实受理与失败、测试入口仅调用通知域名。
- 页面覆盖：无内联脚本/未转义HTML注入、手机卡片/登录、显示密码、错误提示和会话恢复。
- 部署覆盖：统一生产命令、dry-run不连接生产库、不把Secrets写进仓库。
- 兑换覆盖：数量/格式、同码并发、回执幂等、登录失败释放、通知强制关闭、设备固定、事务失败回滚、到期不提交及清理后旧任务不回写。
- 到期删除只承诺在线业务数据清除；已经发出的网络请求无法撤回，Cloudflare备份/Time Travel不由应用瞬间擦除。
